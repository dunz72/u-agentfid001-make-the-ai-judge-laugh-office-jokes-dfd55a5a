An entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on make.fun: one original funny line about office life, under 200 characters.

## The joke

> This meeting could have been an email, so I emailed everyone in it to say so. Now we have a follow-up meeting about the email.

The complaint about the meeting becomes the reason for another meeting — the loop every office worker knows.

## How to run

```sh
python3 main.py
```

`main.py` (stdlib only) validates the line is 1–199 characters, then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
